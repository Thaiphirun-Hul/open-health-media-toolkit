# Contributing to OHMT

Thanks for helping make public-health communication clearer and more accessible.

## Good first contributions

- Improve English or Khmer interface wording.
- Review Khmer translations with a fluent editor.
- Improve keyboard navigation and screen-reader support.
- Add accessible public-health content-planning templates.
- Improve documentation and examples.
- Report bugs and suggest workflow improvements.

## Before opening an issue

Please do not include patient information, screenshots containing personal data, confidential institutional material, or identifiable case histories. Use fictional examples only.

## Pull requests

1. Describe the problem your change solves.
2. Keep changes focused and explain how to test them.
3. Check the interface at desktop and mobile sizes.
4. If changing translations, include both English and Khmer.
5. Never add real patient or confidential data to sample content.

## Health content

This project is a communication-planning tool, not a source of medical advice. Any clinical content or medical claims included in examples must be clearly marked as illustrative and reviewed by qualified professionals before use.
