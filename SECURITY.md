# Security and privacy

This project is a static, local-first planning tool. It is not a secure clinical system and must not be used to store patient records or confidential clinical information.

Please do not submit patient names, contact details, medical record numbers, identifiable images, individual case histories, credentials, or other sensitive information in issues or pull requests.

For a security concern, do not publish exploit details in a public issue. Contact the repository maintainer privately once a maintainer contact channel has been established.
